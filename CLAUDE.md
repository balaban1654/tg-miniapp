# Hunter AI — памятка для Claude

Читай этот файл в начале каждой сессии: здесь договорённости и состояние проекта, чтобы продолжить работу с того места, где остановились, из любой сессии и с любого аккаунта.
Полная история переписки хранится у владельца на ПК (файл `history.md`), её можно прислать в чат, если нужна подробность.

## Как работать
- Всё общение с владельцем и весь текст интерфейса — на русском. Ответы короткие и честные: что сделано, что проверено, что нет.
- «Нарисуй / предложи варианты» — сначала макеты (картинка), без кода. «Делай / делаем / подходит» — согласие делать.
- После каждого изменения:
  - встроенные скрипты HTML: `node -e "...new Function(m[1])..."` по всем `<script>`;
  - сервер: `cd server && npx tsc --noEmit`;
  - Lite (`server/public/lite.html`) — только ES5: `npx -y acorn --ecma5 --silent <(скрипты lite.html)`;
  - проверка на локальной базе `postgres://postgres:pw@127.0.0.1:5432/hunter_test` (`service postgresql start`), сервер на новом порту каждый раз (HTML кешируется при старте):
    `BOT_TOKEN=1:x DATABASE_URL=... PORT=NNNN npx tsx src/index.ts`;
  - скриншоты Playwright: `env -u HTTPS_PROXY NODE_PATH=$(npm root -g) node script.js`, Chromium с `--no-proxy-server`, адрес Office — `/crm#/<раздел>`, вход — cookie `hunter_session` (в `sessions` хранится sha256 токена).
- Сложные правки с `$` и `${}` — Python-скриптом из файла, а не heredoc.
- Коммиты с трейлерами Co-Authored-By и Claude-Session (их даёт система). Без идентификаторов моделей в коммитах.
- Пуш в обе ветки (вторая автоматически выкатывает прод):
  `for b in claude/practical-goldberg-x4znsg claude/telegram-mini-app-funnel-nbqal3; do git push origin HEAD:$b; done`
- PR не открывать. Секреты партнёрки и реальные ключи в репозиторий не класть.

## Что это
- **Mini App** для лидов: `server/public/app.html`.
- **Hunter Office** (CRM): `server/public/office.html`. **Office Lite** для старого iPad: `server/public/lite.html` (ES5, без grid, `-webkit-` flex).
- Сервер: Fastify + pg + grammY, `server/src/*.ts`. Схема БД `db/schema.sql` — идемпотентная, применяется при каждом запуске; разовые миграции закрываются метками в `app_settings`.
- Бот: `hunters_aibot`. Ссылки стримеров: `hunterai.space/<slug>` → `t.me/<бот>?start=s_<slug>`; `?app=1` — пробный режим сразу в Mini App (`startapp`).
- Постбеки Pocket Option: `/postback/<reg|ftd|dep|wd|comm>?secret=…&click_id={click_id}&trader_id={trader_id}…` (`server/src/postback.ts`).

## Правила бизнеса
- Стримеры видят только суммы FTD. Тестовые аккаунты не попадают в статистику и зарплаты.
- «Активный» — только после повторного депозита с суммой. Комиссия статус не меняет.
- Регистрация лида считается по `max(reg)`, FTD/активный — по первому FTD (`leaddate.ts`: `shownStage`, `funnelStageDate`).
- KPI-план (Office → KPI): мин. ставка от 5 FTD, аванс $200 от 30 ч и 5 FTD, цена лида при невыполненном плане $5, допуск по смене в минутах (`shiftTolMin`). Пересчёт открытых месяцев — `recalcOpenMonths` (`accounting.ts`).
- Реферальная система: стримеру за друга $5 (с ноября 2026, разовый пересчёт ноября сделан), смена ставки в настройках пересчитывает открытые месяцы.
- Додепы (градации): Бронза от $500 +$10, Серебро от $1000 +$50, Золото от $3000 +$100, Диамант от $5000 +$300; за лида одна высшая градация, взятая первым депозитом не оплачивается.
