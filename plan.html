Проект · Telegram Mini App + CRM

Воронка для клиентов и CRM для команды

Пошаговый план и макеты всех кабинетов в фиолетовой гамме. Каждый экран ниже показывает, что увидит клиент, стример, тимлидер, медиабайер и админ. Все цифры и имена на макетах примерные.

Как всё устроено

Одна система, три входа: Telegram-бот с Mini App для клиентов, веб-кабинет для команды и API, куда брокер присылает постбеки. Всё держится на одной базе, поэтому клиент видит свой кабинет, а стример видит того же клиента как лида.

Главный путь лида
Ссылка стримера→Домен (Cloudflare)→Бот: /start s_ref→Лид закреплён за стримером→Mini App→Регистрация у брокера→Постбек reg / dep / wd→CRM + пуш + уведомление стримеру

Пример ссылки: https://go.твойдомен.com/s/ivan → t.me/твой_бот?start=s_ivan. Параметр start бот читает при первом заходе и навсегда привязывает человека к стримеру.

Этапы

1

Подготовка и доступы

1–2 дня · делаешь ты
  • Бот в @BotFather, название, аватар, команда меню, домен Mini App.
  • Купить домен и добавить его в Cloudflare (DNS, SSL, защита от ботов).
  • GitHub: репозиторий уже есть, добавим ветки main и dev, секреты для деплоя.
  • Сервер: Ubuntu, Docker, доступ по SSH. Cloudflare Tunnel или проксирование на IP сервера.
  • Узнать у брокера формат постбеков и макросы (click_id, event, amount).
2

Ядро: база, роли, авторизация

4–5 дней
  • Вход через Telegram (проверка initData), без паролей для клиентов.
  • Логин и пароль плюс 2FA для админа, тимлидера, стримера, медиабайера.
  • Роли и права: админ, тимлидер, стример, медиабайер, клиент. Права гибко настраиваются на каждого.
  • Таблицы: пользователи, команды, лиды, события, платежи, планы, ссылки, сообщения, пуши.
3

Реферальные ссылки и бот

3–4 дня
  • Генератор ссылок на домене: на стримера, медиабайера, источник, кампанию.
  • Закрепление лида при /start, защита от перехвата: лид не переходит к другому стримеру.
  • Кнопка «Открыть кабинет» и приветствие по сценарию.
4

Постбеки и CRM

4–5 дней
  • Эндпоинт /postback с подписью и защитой от дублей: регистрация, FTD, повторный депозит, вывод.
  • Статусы лида: новый → зарегистрирован → FTD → активный → отвал.
  • Лента событий, фильтры, поиск, экспорт.
5

Кабинет клиента (Mini App)

5–7 дней
  • Главная, сигналы, история сделок, тренажёр, медиа, профиль.
  • Сигналы публикует админ или аналитик, клиенту приходит пуш.
  • Тренажёр: уроки, тесты, разбор входа по графику, прогресс.
6

Кабинеты стримера и тимлидера, чат

6–8 дней
  • Стример видит только своих лидов, пишет им и отвечает через бота прямо из кабинета.
  • Тимлидер видит команду, результаты каждого и общий план.
  • Передача лида другому стримеру только через тимлидера или админа.
7

Бухгалтерия, планы, медиабайеры

5–6 дней
  • Планы по FTD: общий, на команду, на каждого стримера и медиабайера, по периодам.
  • Ставки и проценты стримеров, ставка за FTD или процент от залива у медиабайера, холды, выплаты.
  • Баланс к выплате, история выплат, штрафы и бонусы.
8

Пуши и рассылки

3–4 дня
  • Триггеры: регистрация, нет депозита через N часов, FTD, новый сигнал, итоги дня.
  • Шаблоны с кнопками и картинками, задержка, сегменты, A/B.
  • Рассылка вручную по сегменту и очередь отправки с учётом лимитов Telegram.
9

Тесты, запуск, поддержка

3–4 дня
  • Тестовые постбеки, нагрузка, резервные копии базы.
  • Деплой через GitHub Actions на сервер, мониторинг и логи.
  • Обучение стримеров и тимлидеров, запуск на небольшой группе.

Что нужно подготовить

GitHub

  • Репозиторий tg-miniapp (есть)
  • Ветки main и dev
  • Секреты: SSH-ключ, токен бота, ключ постбеков
  • Автодеплой при пуше в main

Домен и Cloudflare

  • Один домен, поддомены: app. для Mini App, crm. для кабинетов, go. для ссылок, api. для постбеков
  • Прокси и SSL
  • Правила против ботов на /postback

Сервер

  • 2 vCPU, 4 ГБ RAM для старта
  • Docker, Postgres, Redis, Nginx
  • Бэкапы базы раз в сутки

Технологии

  • Фронт: React + Vite, Telegram WebApp SDK
  • Бэк: Node.js (NestJS), Postgres, Redis
  • Бот: grammY, очередь отправки BullMQ
  • Один адаптивный интерфейс для телефона и сайта
